# 0003 動画収録

Alt+Shift+5の操作パネルでモニターまたは範囲の録画を開始する。旧操作メニューはAlt+Shift+6に移す。録画中はトレイアイコンを変更し、ダブルクリックで停止・保存する。終了指示時もMP4を確定して保存してから終了する。音声は収録しない。FPSとビットレートはINIで指定する。

初期の録画フレーム取得はGDI、エンコードはMedia FoundationのH.264/MP4を使用する。GDIは録画時のみ動かす。実機の性能測定後、必要なら`Windows.Graphics.Capture`への移行を検討する。詳細は[設計書](../design.md)を正本とする。
