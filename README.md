# Win Capture

- Windows 11用のネイティブな常駐キャプチャツール。

## 操作

| キー | 動作 |
| --- | --- |
| Alt+Shift+3 | カーソルがあるモニターを保存 |
| Alt+Shift+4 | 範囲をドラッグして保存。Escで中止 |
| Alt+Shift+5 | 撮影・録画パネルを開く |
| Alt+Shift+6 | 操作メニューを開く |

パネルはTabとEnterで操作できます。Escで閉じます。録画はカーソルがあるモニター、またはドラッグで選ぶ範囲を対象にします。音声は録りません。録画中はトレイアイコンが赤い表示に変わり、ダブルクリックで停止してMP4を保存します。録画中に「終了」を選んだ場合も保存後に終了します。

トレイアイコンの右クリックでも操作メニューを開けます。録画していない時のダブルクリックもメニューを開きます。
静止画の保存後は、撮影対象モニターの右下にミニ表示が約5秒間出ます。クリックすると保存した画像を既定のアプリで開きます。

## 配布と設定

ReleaseのZIPを展開して`capture.exe`を起動します。初回起動時にEXEと同じフォルダーへ`capture.ini`が生成されます。以降はINIを編集してからアプリを再起動してください。保存先は初期設定で`%USERPROFILE%\capture`です。EXEのあるフォルダーに書き込み権限が必要です。

`[Image] format`は`png`、`jpeg`、`jpg`を指定できます。`[General] filename`には`{yyyy}`、`{MM}`（月）、`{dd}`、`{HH}`、`{mm}`（分）、`{ss}`を使えます。`[Video] fps`と`bitrate`で録画速度とビットレートを指定します。必須項目が欠落・不正な場合はエラーを表示します。

## ビルド

Windows 11のMSVC環境で`cmake -S . -B build -A x64`、`cmake --build build --config Release`を実行します。GitHub Actionsも同じ構成でZIPを生成します。設計と実装状況は[docs/design.md](docs/design.md)を参照してください。
